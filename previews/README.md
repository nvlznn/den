# 預覽

所有給你檢查的圖片集中在這裡。

- `characters.png`：所有角色與蛋的素材表。
- `onboarding/overview.png`：選蛋與三頁 guide 的總覽。
- `onboarding/`：首次開啟流程的個別畫面。
- `app/`：網站使用的六張深色模式 app 截圖與 widget 預覽素材（SVG 示意圖）。
- `archive/`：已移除的 iCloud guide 與舊版總覽。

依照你的要求，這次沒有重新截圖。Guide 沿用既有截圖，底部的頁數圓點仍是當時的四頁；目前程式已改為三頁。

網站執行所需的截圖仍保留在 `website/assets/screens/`；這裡的 `app/` 是方便檢查的副本。
